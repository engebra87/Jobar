معركة جوبر — ملفات التطبيق
==========================

هذه الملفات هي اللعبة كتطبيق ويب قابل للتثبيت (PWA): تعمل بملء الشاشة وبالعرض، وبدون إنترنت بعد أول فتح.

الملفات:
- index.html ........ اللعبة
- three.min.js ...... مكتبة الرسم ثلاثي الأبعاد (محلية، لا تحتاج إنترنت)
- manifest.webmanifest + sw.js ... ما يجعلها تطبيقاً قابلاً للتثبيت ويعمل دون اتصال
- icon-512.png / icon-192.png / apple-touch-icon.png ... أيقونة التطبيق
- privacy.html ...... سياسة الخصوصية (يطلبها متجر جوجل بلاي)

الخطوة 1: ارفع الملفات على رابط مجاني (من الهاتف)
1) افتح github.com وأنشئ حساباً.
2) اضغط + ثم New repository، سمّه jobar، اجعله Public، ثم Create.
3) اضغط "uploading an existing file" وارفع كل الملفات (بعد فك ضغط الملف المضغوط بمدير الملفات).
4) اضغط Commit changes.
5) Settings ثم Pages، اختر Branch: main ثم Save.
6) بعد دقيقة يصبح رابط اللعبة: https://اسم-المستخدم.github.io/jobar/

الخطوة 2: ثبّتها على الهاتف (مجاناً، بدون متجر)
- افتح الرابط في Chrome ثم القائمة ⋮ ثم "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية".

الخطوة 3: انشرها على Google Play
1) افتح pwabuilder.com والصق رابط اللعبة، ثم Package for stores ثم Android ثم Generate.
2) نزّل الملف الناتج: فيه ملف .aab (للمتجر) وملف signing key (احتفظ به جيداً، تحتاجه لكل تحديث) وملف assetlinks.json.
3) ارفع assetlinks.json إلى مجلد .well-known في نفس المستودع (حتى يختفي شريط العنوان داخل التطبيق).
4) أنشئ حساب مطوّر في play.google.com/console (25 دولاراً مرة واحدة).
5) أنشئ تطبيقاً جديداً، وارفع ملف .aab، واملأ صفحة المتجر: الأيقونة icon-512.png، لقطات شاشة، الوصف، ورابط سياسة الخصوصية:
   https://اسم-المستخدم.github.io/jobar/privacy.html
6) الحسابات الشخصية الجديدة تحتاج غالباً اختباراً مغلقاً مع 12 مختبِراً لمدة 14 يوماً قبل النشر للعامة.

ملاحظة: اللعبة تتناول صراعاً حقيقياً وأطرافاً سياسية حقيقية، وقد تراجعها جوجل بدقة أكبر ضمن سياسة "الأحداث الحساسة" وتطلب تصنيفاً عمرياً مناسباً للعنف.
